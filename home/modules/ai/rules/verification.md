# Verify before asserting

Before stating a specific fact — what something is in this repo, what a tool
can do, or that an external project exists — check it: the repo for local
facts, the installed version's docs/source or a search for external ones.
Memory and name similarity are not evidence.

- Verified means a source you read says it; name the source. A search that
  didn't turn it up is not confirmation.
- Before proposing custom code or a third-party add-on, check what the
  software already in use provides.
- When challenged, re-check before answering; don't defend or explain the
  claim from memory.
- If you can't verify it, say so.
